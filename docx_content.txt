RESOLVEIT
College Grievance & MaintenanceIssue Catalogue
A categorized reference list for hostel, academics, campus facilities, student life and support services

Purpose. This document is a broad issue catalogue for a college grievance and maintenance website. Students can select a main category and subcategory, choose an issue, and add their own description, location, urgency, and supporting evidence when submitting a report.
How to use this catalogue. Use the listed issues as suggested options, not as assumptions that every issue exists on campus. Keep an “Issue Not Listed / Other” option available. For sensitive concerns—such as harassment, discrimination, health, emotional well-being, or safety—route reports to an authorized and confidential process rather than exposing them publicly.
Recommended fields in the website: Main category • Subcategory • Issue title • Description • Location/building • Date/time • Urgency • Optional attachment • Status • Assigned department • Updates • Resolution confirmation.

Implementation Notes for the Website
Keep category and location separate. For example, “Building Maintenance” is a category, while “Academic Block / Hostel Block / Mess / Library / Sports Ground” is the location.
Avoid duplicate reports where possible. When a student submits a report, the system can suggest similar open reports for the same issue and location.
Use clear statuses. Suggested statuses: Submitted, Under Review, Assigned, In Progress, Awaiting Student, Resolved, Reopened, and Closed.
Add urgency carefully. Suggested levels: Low, Normal, High, and Emergency. Emergency reports should display official campus emergency contacts and follow the college's actual response process.
Protect sensitive reports. Health, emotional well-being, harassment, discrimination, safety, and staff-conduct reports should have restricted access and not be visible on a public feed.
Let students add details. The catalogue should not replace a student's own description. Allow a custom description and “Other / Issue Not Listed” in every main category.
Track accountability. Each report should have a unique ID, submission date, assigned department/person, status history, updates, and a resolution note.
Use campus-approved terminology. Before launch, review the categories with hostel, mess, laundry, academic, facilities, IT, security, student-support, and administration teams.
