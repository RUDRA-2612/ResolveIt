Docker Guide
============

This document describes the guide for docker usage in this project to aid in
development.

Docker summarized
-----------------

Your machine runs Docker. Docker runs something called containers. Containers
will provide you with all the tools you need. Your source code lives in your
machine and is mounted into containers.

A docker image is basically a recipe containing a filesystem and everything else
needed to create a container. A container is a running instance of an image.

Docker compose is going to help us avoid repetition by describing the entire
environment in one file. Then, you can just do $ docker compose up $, which
setups things as described in the yaml file.

Command Reference
-----------------

These are going to be the 90% of the commands that you're going to need.

$ docker compose up

$ docker compose up -d

$ docker compose ps

$ docker compose logs -f app

$ docker compose exec app bash

$ docker compose exec app pnpm <your pnpm subcommands>

$ docker compose up --build
